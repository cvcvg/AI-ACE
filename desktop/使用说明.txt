AI-ACE 桌面版  使用说明
================================

整合后唯一的桌面端：原生 Windows 程序（C# / .NET Framework 4.x），不依赖 Node.js、Electron、浏览器。

目录结构：
  build.bat        双击即可重新编译（调用系统自带 csc.exe），成功打印 BUILD OK，失败打印 BUILD FAILED
  src\             全部源码：10 个 .cs（Boot.cs 启动进度与镜像导入、Setup.cs 一键部署向导、DataDir.cs 数据目录、NetGuard.cs 安全自检，其余是界面、网络与配置）
  tools\           简版命令行入口 AI-ACE桌面版.bat（exe 打不开时救急用）
  build\           编译产物 AI-ACE.exe
  icon.ico         程序图标

第一次用，按这个顺序：

先记住一件事：装好以后，日常双击包根（AI-ACE 文件夹最外层）的 AI-ACE.exe 就是启动器，第一次运行它是安装向导——窗口一出现就自己开始装，不用点任何按钮。

1. 双击 build\AI-ACE.exe。
   先出现一个无边框的小进度窗，依次显示：检查环境 → 启动 Docker → 检查镜像 → 启动服务 → 等待界面就绪。
   第一次要等 1 到 3 分钟；服务就绪后进度窗自动关闭，主窗口出现。

2. 如果弹出「缺少基础镜像」，说明这台电脑还缺几个镜像。
   点「选择 tar 导入…」，选中你拷过来的镜像包（*.tar），程序会自己执行 docker load 导入（大包可能几分钟）。
   导入完会自动重新检查并接着启动，不用你管。
   也可以点「以演示模式打开」：跳过服务检查直接进界面，只适合看界面，聊天和任务功能不可用。

3. 关窗口不会退出，程序缩到右下角托盘。托盘右键菜单：打开窗口 / 新对话 / 重启服务 / 打开输出文件夹 / 查看日志 / 数据位置… / 安全自检 / 退出。
   重启服务 = 重新拉起 docker compose（进度显示在状态栏，完成后自动刷新）；查看日志 = 记事本打开程序目录下的 startup.log（启动各步骤与失败原因都记在里面，超过 1MB 自动清空重写）。桌面端不会自动打开浏览器；控制中心是网页版，需要时自己用浏览器访问 http://127.0.0.1:9000。
   想彻底退出用「退出」；想再打开：双击托盘图标，或再双击 AI-ACE.exe（不会开出第二个实例）。
   数据位置可在托盘「数据位置…」里改，会自动搬（默认 D:\AI-ACE-data，别放 C 盘）。

4. 主窗口右上角的「设置」里可以改：服务地址（Open WebUI）、任务服务地址（ace-agent）、API Key / Token、温度、上下文轮数。

出问题怎么办：
  · 进度窗停在「启动 Docker」→ 这台机器没装 Docker Desktop，或它启动太慢；手动打开并等它显示 Running 后再双击。
  · 进度窗停在「启动服务」，会给出「仍然打开界面 / 关闭」两个按钮：先确认 Docker 在跑，也可以先打开界面稍后在设置里改服务地址。
  · 想看命令行输出和具体报错 → 运行 tools\AI-ACE桌面版.bat（PowerShell/CMD 窗口里能看到 docker 的原始输出）。
  · 提示找不到 AI-ACE 目录 → 把 AI-ACE 文件夹放在本程序上两级的同一磁盘，或设置环境变量 AI_ACE_ROOT 指向它。
  · 启动失败时错误会留在进度窗上，窗口不会自己消失；按提示处理后重开程序即可。

注意：本程序完全离线运行，不会联网，也不上传任何数据。
安全自检：桌面端托盘菜单里的「安全自检」；容器出网拦截与自证的脚本在 G:\AI-ACE\desktop\安全\联网隔离.ps1（双击同目录 联网隔离.bat 也行：无参只审计、-Apply 装拦截、-Remove 回滚），报告落在同目录 报告\ 下。
